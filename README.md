# JobXHunter

AI-powered platform for automated job hunting.

## Features
- User management
- Resume upload & parsing
- AI vacancy matching
- Automated job notifications
- Job filtering

## Tech Stack
- Java 21
- Spring Boot
- PostgreSQL
- Liquibase
- Maven
- Quartz
- Spring AI
- Angular (planned)

mvn spring-boot:run
